# Appscrafter — CTMS marketing site

Static launch website for **CTMS (Clinic Top Management System)** by Appscrafter.

- Single self-contained page: [`index.html`](index.html) (HTML + CSS + JS inline)
- Assets: `appscrafter-logo.svg`, `og-image.svg`
- Only external dependency: Google Fonts

## Features
Interactive product demo, English ⇄ Arabic (RTL) toggle, light/dark themes,
geo-detected local-currency pricing (monthly / annual), comparison table, FAQ,
WhatsApp chat button, SEO structured data.

## Deploy
No build step — it's a static site.

**Vercel:** import this repo (Framework Preset: *Other*, Root: `./`), or run `vercel --prod` from this folder.

**Any static host:** upload the folder as-is (Netlify, Cloudflare Pages, GitHub Pages, etc.).
