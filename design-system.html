CTMS Design System

A calm, precise system for a healthcare platform: warm neutral surfaces, deep navy type and the CTMS purple brand gradient. All tokens live in assets/ctms.css, adapt to dark mode, and use logical properties so every component works in Arabic (RTL).

Colour

Neutrals carry the interface; the brand purple marks action and data; status colours are reserved for meaning.

Typography

Geist for Latin, IBM Plex Sans Arabic for Arabic, Geist Mono for figures and codes. Headings use tight tracking; Arabic resets tracking to zero and opens line height.
